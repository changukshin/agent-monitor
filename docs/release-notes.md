# Agent Monitor v0.1.0 release candidate

Windows x64, per-user installation. The package includes the production Rust collector and native dashboard, Windows PowerShell setup/removal, configuration example, operating guides, license notices and a build manifest. No Phase 1 binaries are distributed. The ZIP and checksum are CI review artifacts pending explicit release approval.

Managed Codex CLI 0.167.0 supports sampled input waits, clearance and latest-turn completion/interruption on Windows. Passive Claude Code 2.1.287 provides limited identity and activity. Native WSL2, approval/failure/exit states and complete transition delivery are deferred. Use the installation guide and review the installed-product validation report in the repository before deployment.
